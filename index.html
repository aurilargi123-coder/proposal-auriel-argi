PROJECT

Proyek IoT

Beberapa proyek yang pernah saya kerjakan

Lampu Otomatis Berbasis ESP32

Proyek ini merupakan sistem lampu otomatis berbasis ESP32 yang dapat dikontrol dan dimonitor menggunakan aplikasi Blynk.

Lampu dapat dikontrol secara manual menggunakan tombol ON/OFF dan dapat diatur berdasarkan jadwal melalui Blynk.

Lampu Otomatis Menggunakan Sensor LDR

Proyek ini menggunakan Arduino Uno dan sensor LDR untuk membuat sistem lampu otomatis berdasarkan intensitas cahaya.

Ketika kondisi lingkungan gelap, sistem dapat mengaktifkan lampu secara otomatis. Ketika kondisi menjadi terang, lampu dapat dimatikan kembali.
